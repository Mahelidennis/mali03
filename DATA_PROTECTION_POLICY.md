# Mali Financial Assistant - Data Protection Policy

**Last Updated: December 2024**

## 1. Introduction

This Data Protection Policy outlines how Mali Financial Assistant ("Mali", "we", "us", "our") protects, processes, and manages personal data in compliance with the Data Protection Act 2019 (Kenya) and other applicable data protection laws.

## 2. Legal Framework

### 2.1 Applicable Laws
- **Data Protection Act 2019 (Kenya)**: Primary legal framework
- **GDPR (EU)**: For EU users and data transfers
- **CCPA (California)**: For California residents
- **Industry Standards**: Financial services data protection standards

### 2.2 Data Protection Principles
- **Lawfulness**: Process data lawfully and fairly
- **Purpose Limitation**: Process data for specified purposes only
- **Data Minimization**: Collect only necessary data
- **Accuracy**: Keep data accurate and up-to-date
- **Storage Limitation**: Retain data only as long as necessary
- **Security**: Implement appropriate security measures
- **Accountability**: Demonstrate compliance with data protection laws

## 8. Data Retention and Deletion

### 8.1 Retention Periods
- **Active Accounts**: Data retained while account is active
- **Inactive Accounts**: Deleted after 2 years of inactivity
- **Financial Data**: Retained for 7 years for regulatory compliance
- **SMS Data**: Retained per user preference (default: 1 year)
- **Technical Data**: Logs retained for 90 days, analytics for 2 years

### 8.2 Deletion Procedures
- **User Request**: Immediate deletion upon verified user request
- **Account Closure**: Deletion within 30 days of account closure
- **Automatic Deletion**: Scheduled deletion of expired data
- **Secure Deletion**: Permanent deletion using secure methods

### 8.3 Data Anonymization
- **Research Data**: Personal identifiers removed for research
- **Analytics**: Data anonymized for aggregate analysis
- **Historical Data**: Old data anonymized before long-term storage
- **Third-Party Sharing**: Data anonymized before sharing

## 9. Data Subject Rights

### 9.1 Right to Information
- **Transparency**: Clear information about data processing
- **Purpose**: Information about why data is processed

- **Rights**: Information about data subject rights

### 9.2 Right of Access
- **Data Copy**: Receive a copy of all personal data
- **Processing Information**: Information about data processing
- **Third-Party Sharing**: Information about data sharing
- **Automated Decisions**: Information about automated decision-making

### 9.3 Right to Rectification
- **Correction**: Correct inaccurate personal data
- **Completion**: Complete incomplete personal data
- **Verification**: Verify data accuracy and completeness
- **Updates**: Regular updates to keep data current

### 9.4 Right to Erasure
- **Deletion**: Request deletion of personal data
- **Withdrawal of Consent**: Delete data when consent is withdrawn
- **Unlawful Processing**: Delete unlawfully processed data
- **No Longer Necessary**: Delete data no longer needed

### 9.5 Right to Restrict Processing
- **Accuracy Disputes**: Restrict processing while accuracy is verified
- **Unlawful Processing**: Restrict unlawful processing
- **Objection**: Restrict processing when objecting
- **Retention**: Restrict processing while retention is assessed

### 9.6 Right to Data Portability
- **Export**: Receive data in a structured, machine-readable format
- **Transfer**: Transfer data to another service provider
- **Format**: Receive data in commonly used formats
- **Direct Transfer**: Direct transfer where technically feasible

### 9.7 Right to Object
- **Processing Objection**: Object to processing based on legitimate interest
- **Marketing Objection**: Object to direct marketing
- **Profiling Objection**: Object to automated decision-making
- **Scientific Research**: Object to processing for research purposes
